# Changelog

## 1.0.0 (2026-11-09)

First release.

- Dungeon quest list for all WoW Forever dungeons, filtered by faction, race and class.
- Status colors: green (in log), yellow (available), blue (prerequisite workable), red (level-locked).
- Next-step zone per quest (`[Zone]`, `[INSIDE]`, red `!` for unknown quest giver).
- World map pins and click-to-show quest giver / prerequisite, with optional waypoint.
- Right-click menu: hide quest/dungeon, Ignored section, copyable WoWHead link.
- Minimap button and addon compartment entry.
- Horde and Skyborne are untested.
